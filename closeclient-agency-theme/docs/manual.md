# CLOSECLIENT AGENCY THEME - User Manual

## Welcome
Thank you for choosing the CLOSECLIENT AGENCY THEME. This theme is designed for professional service providers who want a modern, high-converting, and easy-to-manage website.

## Getting Started

### 1. Installation
1. Upload the `closeclient-agency-theme` folder to your `/wp-content/themes/` directory.
2. Upload and activate the `CLOSECLIENT CUSTOMIZER PRO` plugin.
3. Activate the theme in **Appearance > Themes**.

### 2. Creating Key Pages
Go to **Pages > Add New** and create the following pages, assigning the corresponding **Page Template** in the Page Attributes sidebar:
- **Home**: Use the "Homepage" template.
- **About Us**: Use the "About Us" template.
- **Contact**: Use the "Contact Page" template.
- **Landing Page**: Use the "Landing Page" template for marketing campaigns.

To set your homepage, go to **Settings > Reading** and set "Your homepage displays" to "A static page", then select your "Home" page.

### 3. Adding Content (CPTs)
The theme uses Custom Post Types for specialized content:
- **Services**: Add your practice areas or services here.
- **Testimonials**: Add client feedback.
- **Team**: Add your staff members.
- **Gallery**: Add portfolio items or office photos.

## Customization

All design settings are located in **Appearance > Customize > Theme Options**.

### Global Design System
- **Colors**: Set your brand's primary and secondary colors.
- **Typography**: Choose from over 50 Google Fonts and set sizes/weights.
- **Spacing**: Adjust the overall "breathability" of your site.
- **Borders & Radius**: Control the roundness of buttons and cards.
- **Shadows**: Add depth with customizable box shadows.

### Page Content
Manage specific page sections under **Appearance > Customize > Page Content**.
- **Homepage**: Reorder sections (Hero, Practice Areas, Testimonials) using the drag-and-drop Sorter.
- **About Us**: Set the heading for your team section.

## Advanced Features

### Dark Mode
Enable Dark Mode in **Theme Options > Dark Mode**. You can customize the specific colors used when Dark Mode is active.

### Export/Import
You can export your Customizer settings as a JSON file to backup or move to another site. Find this under **Export/Import/Reset** in the Customizer.
